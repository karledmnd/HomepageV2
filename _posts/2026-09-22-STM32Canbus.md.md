## 📌 Project Overview

This was one of my first boards that i designed. Also, the only project created using EasyEDA.

- **Primary Goal:** Communicate with a vehicles CAN-BUS, retrieve information. Configurable Baudrate.
- **Tech Stack:** EasyEDA, STM32F302, TCAN332. Designed & flashed on M1 Macbook using ST-Link V2.
- **Status:** Developed, ready to use.

---

## 🛠️ Key Specifications & Hardware Architecture

| Feature | Details / Components |
| :--- | :--- |
| **Microcontroller** | STM32F302C6T6 |
| **Can Tranceiver** | TCAN332DR CAN transceiver, compatible with ISO 11898 |
| **Power** | 12V Buck Converter System with Filtering |
| **Intefaces** | CAN-BUS, USB-C, SWD |
| **Indicators** | Power & CAN RX/TX LED's |
| **Stack-up** | 4-layer board - Signal, GND, 3V3, Signal |
